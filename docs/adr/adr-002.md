# ADR-002: Use Vue Framework instead of React

**Date:** 2026-10-11
**Status:** accepted

## Context

When developing a web application, it is important to choose a framework that can help speed up development, by making it easier to manage the client-side code. React is perhaps the most popular frontend framework out there, but I am not too familiar with it, and prefer the way Vue does things.

## Decision

I decided on using Vue, to build out the frontend, where it is reponsible for the code and implemntation in the Presentation layer.

## Consequences

Vue will make keeping track of the state in the application much easier. The component nature of Vue where the logic and the rendering are kept in each component file, makes the separation of concerns for the UI more natural. The downside, is that I cannot get experience using React, which is something I accept for this course.
