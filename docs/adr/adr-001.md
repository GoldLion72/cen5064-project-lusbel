# ADR-001: What is being Built

**Date:** 2026-10-11
**Status:** proposed

## Context

This project is expected to be completed within a semseter. 3-5 use cases are expected to be developed throughout the course. Developing web applications is something that I have experience with.

## Decision

I have decidied on building a fitness tracker web app. It has the following tiers: presentation -> service -> domain -> data. It will mainly use JavaScript, HTML, and CSS.


## Consequences

Developing 3-5 core use cases should be easier with this project. The challenging asepcts will be to cleanly separate the application by its tiers, as the service tier can potentially be easily mixed with the presentation tier.
